# Sécurité

## Signaler une vulnérabilité

Utilisez le **signalement privé** de GitHub : onglet *Security* du dépôt concerné, puis *Report a vulnerability*. N'ouvrez pas d'issue publique.

Indiquez le dépôt, la version (commit ou tag), les étapes pour reproduire et l'effet constaté. Nous accusons réception sous 7 jours.

## Périmètre

- Les dépôts de l'organisation `labatailledefrance`.
- Le serveur officiel du jeu, `srv.labatailledefrance.fr`, **sans test intrusif** : pas de déni de service, pas d'accès aux données d'autrui. Un test d'abus du protocole se fait sur un serveur local.

Les mods ne sont pas cloisonnés : exécuter un mod, c'est exécuter son code. Ce n'est pas une vulnérabilité.
